# LUXOR PHARAOH DAY — Production Deployment

## Release gate

Supported runtime: **Node 24.x / npm 11+**.

Permanent production requirement: a committed, real `package-lock.json` generated by npm.

### Bootstrap sequence

1. Upload the repository source.
2. Run **Actions → Bootstrap real package-lock.json → Run workflow**.
3. Confirm Node 24 and npm 11+.
4. Confirm `npm install --package-lock-only` succeeds.
5. Confirm `npm ci`, `npm run preflight`, and `npm run build` succeed.
6. Download the generated `package-lock.json` artifact.
7. Commit `package-lock.json` to the repository root.
8. From that point onward, use `npm ci` in CI and Vercel.

## Vercel

- Framework: Next.js
- Install Command: `npm ci`
- Build Command: `npm run build`
- Root Directory: repository root
- Production environment variable: `NEXT_PUBLIC_SITE_URL=<actual production origin>`
