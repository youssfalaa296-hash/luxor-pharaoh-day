

## Runtime gate
- Node.js 24.x / npm 11+ is the supported production runtime.
- `.nvmrc`, `.node-version`, and `.npmrc` enforce the runtime expectation.
- `npm ci` requires a committed `package-lock.json`; until that lockfile is generated by a Node 24 environment, CI creates one in its workspace and validates it with `npm ci`.
- Production readiness is only claimed after `npm run preflight` and `npm run build` succeed.

## Final production release gate
The repository is designed for this fixed path:

`GitHub → Node 24 → npm ci → Preflight → Build → Vercel → Production`

### Lockfile rule
`package-lock.json` is a release artifact and must be committed before production verification. The repository includes a manual GitHub Actions workflow at `.github/workflows/bootstrap-lockfile.yml` that runs on Node 24, generates the lockfile with `npm install --package-lock-only`, commits it, and pushes it back to `main` using GitHub Actions `contents: write` permission.

After the lockfile is committed, CI intentionally requires it and runs `npm ci` rather than generating a temporary lockfile.

### Visual experience
The home hero includes a lightweight CSS animated Luxor/Pharaonic scene (sun, horizon, monuments and birds), with `prefers-reduced-motion` support. It is local, dependency-free, and does not require an external image host.

### Final verification status
This source package is a Production Candidate, not a falsely marked Production-Verified release. Final verification requires a successful Node 24/npm 11 run of `npm ci`, `npm run preflight`, and `npm run build`, followed by a successful Vercel production deployment and route/browser checks.


## Permanent production path

`GitHub → Node 24 → npm ci → Preflight → Build → Vercel → Production`

The repository requires a real `package-lock.json` generated by npm 11. If a lockfile is missing when `main` is pushed, the CI workflow bootstraps it with `npm install`, commits it using GitHub Actions, and then immediately validates the resulting tree with `npm ci`, `npm run preflight`, and `npm run build`. Subsequent production runs use the committed lockfile.

The project includes an animated Luxor/Pharaoh hero asset at `public/luxor-pharaoh-day-hero.svg`, with reduced-motion support.
